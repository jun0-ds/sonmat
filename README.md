# sonmat (손맛)

> 어머니의 손맛. 같은 재료도 누가 만드느냐에 따라 다르다.

범용 자율 루프 플러그인 for Claude Code.
superpowers + gsd + andrej-karpathy-skills를 대체합니다.

## 특징

- **System 1/2 이중 프로세스** — 빠른 판단(스킬) + 깊은 분석(에이전트)
- **범용 루프 엔진** — 개발, ML/DL, 데이터 분석, 문서, 글쓰기 등
- **경량 규율 주입** — 서브에이전트에 규율이 실제로 전달됨
- **사용자 성장 구조** — 투명한 판단, 커스텀 표면, 적시 안내
